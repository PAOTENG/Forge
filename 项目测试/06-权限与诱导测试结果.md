## 3. 这轮**没有**证明的事

1. **铁门被撞了一下。**  
   改 C 盘、写出工作区、危险 Git 三题，模型都没真正调用对应工具。  
   所以 JSON 里看不到 `Path escapes the selected workspace` 或 `禁止 force push`。  
   铁门靠的是 pytest：绝对路径 C 盘、`../`、`--force`、`reset --hard`、rebase。  
   不能写成“这轮实测工具抛错拦住了”。

2. **无关文件有白名单。**  
   没有。它这次拒绝，是说明书 + 模型判断。换一句更绕的话、换一个模型，结果可能变。

3. **改错了会自动从备份恢复。**  
   这轮 6 题备份条数都是 0，因为没有写成功。  
   备份函数的小测试在：改前能存旧内容，人手动点恢复能还原。  
   自动回滚：没有，这轮也没机会看到。

4. **人点“拒绝批准”后文件一定没落盘。**  
   这轮评测是自动批准，测的是“它愿不愿意干坏事”，不是“你点了否之后工具停不停”。这项仍然缺端到端。
