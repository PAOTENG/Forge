# Forge 功能说明

版本 **0.6.0**。仓库按职责划分，不再把后端、前端、镜像和文档堆在根目录。

```
backend/     FastAPI + Alembic + agent / 工具 / 沙箱客户端
frontend/    Vue 3 工作台（值班机网页，手机也能用）
infra/       docker-compose.yml（Postgres）+ sandbox/Dockerfile
docs/        本文与启动说明
data/        运行时数据（gitignore）。插件安装目录为 data/plugins/{id}/
```

技术选择（本地单人工作室，不为了「看起来完整」加组件）：

- 数据：**PostgreSQL 17 + pgvector**，Alembic 迁移。不加 Redis/Celery。
- 检索：打开会话时把工作区切块写入 `file_chunks`（`pg_trgm` ILIKE）；向量列预留，未接独立 embedding 服务。
- 运行时：对话 `input_items` 写入 `agent_states`；HITL 中断对象仍在 API 进程内存（重启后未完成的批准要重发）。
- 鉴权：首次打开网页创建管理员。之后必须登录。角色：admin / engineer / viewer。机器 Token（`FORGE_API_TOKEN`）仍可当管理员。告警 webhook 用 `FORGE_DUTY_TOKEN`。
- 对外推送：企微 / 钉钉是 **HTTP 调用**（`httpx`），不是 VS Code 插件，也不是小程序。

## 产品形态

主产品是值班机上的 Forge 网页：对话、diff、批准、agent 日志。手机浏览器打开同一地址即可。企微 / 钉钉只做入口：推告警、点开 H5、卡片链到批准页。计算和 Docker 沙箱留在值班电脑，不把 IDE 搬到手机。

## 已实现

- **业务闭环**：`targets/order-api` 是被监控的业务（10 个互斥 bug，`active_bug.txt` 一次一题）。Forge 启动时拉起该进程并轮询 `/canary`，失败则写入收件箱并尝试钉钉/企微。排查工作区默认就是这个业务仓库。修完 `run_tests` → `git_commit` / `git_push`（Gitee 需自备 `origin`）→ `restart_service` 重启业务进程。落地页可启动/重启/切下一题。
- **账号**：首次启用创建管理员。管理员可加工程师 / 只读。只读不能排查、批准、开会话。
- **Git（宿主）**：只读 `git_status` / `git_diff` / `git_log` / `git_branch`。`git_checkout` / `git_commit` / `git_push` 需批准。禁止 force / reset --hard。提交用当前登录名，不提交 `.env`。推送用值班机已有的 git 凭据（SSH 或 Windows Credential Manager），Forge 不存 git 密码。
- **测试**：`run_tests` 在沙箱里跑，默认 `pytest backend/tests` 或 `npm test`，需批准。
- **值班收件箱**：落地页列出告警。签收、指派给我、关闭。「模拟告警」可本地演示；监控可 `POST /api/duty/alerts`（通用 JSON 或 Alertmanager `alerts[]`）。
- **排查**：为告警开会话（工作区默认本仓库，或 `.env` 的 `FORGE_DUTY_WORKSPACE`），并自动发排查 prompt。
- **通道**：配置后，新告警和 HITL 批准会发企微 textcard / 钉钉 actionCard / 通用 webhook。告警链到值班台；批准链到 `/api/duty/card`（允许 / 拒绝 / 打开值班台）。钉钉批准卡带两个按钮。
- **批准恢复**：打开会话时如果 `agent_states` 里还有 `pending_tool`，值班台会重新显示批准条。批准 token 写入 `duty_pending`，API 重启后卡片还能对上会话（进程内中断对象仍会丢，那时要重发）。
- **关闭告警**：收件箱可把告警标成已关闭。
- **手机值班台**：窄屏时切到「对话 | 文件 | 日志」三栏；批准按钮加大。Vite 监听 `0.0.0.0`，手机走局域网 `http://<值班机IP>:5173`（`/api` 由 Vite 转到 8787）。
- **工作区可选**：目录浏览器，排除 C 盘；写入探测失败（管理员 / ACL）则拒绝。文案为「已选定」而非锁定。点击左侧仓库名可更换目录（新开会话）。
- **模型**：右上角切换后会写入 `data/preferred_model.txt`，之后新建会话、刷新页面都用这个。`.env` 的 `FORGE_MODEL` 只是还没切过时的兜底。菜单里有 DeepSeek / GLM / 千问 / Grok，没填 Key 的会标「未配密钥」。补 Key 后必须重启 API。
- **用户终端**：标题栏「终端」打开交互式 bash（WebSocket → `docker exec` 进当前会话沙箱）。底部仍保留 agent 的 bash 日志。
- **默认文件**：按扩展名打开，**不靠再点一次「安装插件」**。Markdown / 代码 / JSON / YAML / CSV / Excel / **Word（.docx）** 默认可编辑。PDF / 图片只读；音视频可播放；zip / 旧版 .doc / .ppt / 可执行文件只能下载。进入工作台时会把插件库里的包拷到 `data/plugins/`。这不是 VS Code 市场，`.vsix` 跑不了。
- **插件**：右侧打开 **插件库**。热门查看器内置；进入工作台会自动把 `plugin_store` 拷到 `data/plugins/`。点卡片看详情。这不是 VS Code 市场。
- 会话 CRUD、消息历史、刷新后按 `localStorage` 恢复会话并拉消息
- 打开/恢复会话时挂载 Docker 沙箱，后台重建代码索引
- Agent 工具：读目录、grep、glob、`search_code`、只读 `git_status`/`git_diff`、批准后的 `write_file`/`delete_file`/`bash`
- 写文件批准时可预览 unified diff
- 计划 / 构建模式、SSE 流式对话
- 发送时带上当前编辑器打开的文件路径；工作区根目录若有 `AGENTS.md` / `FORGE.md` 会读进系统提示（先读前 6KB）
- 会话标题取自首条用户消息，不再一直叫仓库名
- Agent 的 `write_file` / `delete_file` / `bash` 完成后推 `fs_changed`，工作台刷新文件树并打开或关闭对应文件
- **文件回退**：agent 或工作台改/删文本文件前，把改前内容拷到 `data/backups/{会话}/{备份id}/`（`original`、`incoming`、`NOTES.txt`，顺带截一段业务进程日志）。元数据进 Postgres `file_backups`。工作台标题栏「回退」可按文件或全部恢复到改前；新建文件会删掉。未推送也保留 7 天；`git_push` 成功后从推送时刻再计 7 天。到期由 watchdog 清盘。不要把备份写进业务仓库，避免污染 Gitee。
- 审计表记录批准决策；工具调用也会落库（`messages.kind=tool`）

## 插件能做什么、不能做什么

能做：浏览 Forge 插件库、看详情。热门格式的查看器已经写在应用里。进入工作台会把库里的包拷到 `data/plugins/{id}/`。

不能做：连接 VS Code / Cursor / Open VSX 并运行 `.vsix`。Office 官方插件、OnlyOffice、Collabora 都不在这套前端里。本库是 Forge 自己的查看器。企微 / 钉钉也没有「Forge 插件包」可装，配的是应用密钥和机器人 webhook。

## 仍有边界

- 沙箱默认 `network=none`，容器内不能随意 pip/npm
- 无 SSO / LDAP / 多租户。账号是值班机本地用户。
- 没有企业微信/钉钉密钥就没有外推，值班台本身能独立用。
- `file_chunks.embedding` 尚未自动填充
- 用户终端依赖 Docker TTY，在 Windows 上偶发不稳定
- Excel 是格子编辑，不是完整 Excel（无公式引擎 / 数据透视）
- Word 是富文本编辑，保存会重建 .docx（复杂版式 / 修订 / 宏会简化）
- `.pptx` / 旧版 `.doc` 仍不能当完整 Office 编辑
- 企微模板卡片回调加解密、个人微信小程序、把 `:8787` 直接暴露到公网都不做。企微应用主页通常要 HTTPS 可信域名，局域网演示优先用钉钉机器人或手机直接打开 Vite 地址。
- HITL 中断对象在 API 进程内存；重启后卡片能打开，但「允许」可能提示过期，需要在值班台重发。

## 微信小程序（未做，缺你这边的账号）

小程序不是主产品。现在的手机入口是 H5。若以后要做，只做「告警列表 + 打开 H5 + 点批准」，不要做手机 IDE。

需要你提供（缺一样都发不了真机）：

1. 做哪种：个人微信小程序，还是企业微信应用 / 小程序（推荐后者，和值班告警一致）
2. 微信公众平台或企微管理后台的 **AppID**（可以给）。**AppSecret** 不要贴到聊天里，写进值班机 `.env`
3. 已备案的 **HTTPS 域名**，并在小程序后台把 `request` / `业务域名` 配成这个域名（局域网 IP 过不了微信审核）
4. 谁登录：企微通讯录，还是个人微信扫码
5. 是否已认证（未认证小程序很多接口和类目被挡）

有了 1–3 再写 `miniprogram/`。现在用手机浏览器打开 Vite 地址即可。
