# 会话沙箱从零实现（对照 Forge）

面向：在一个**新项目、进度为 0** 时，做一个和 Forge 同类的会话沙箱。  
环境：Windows + PowerShell。  
目标：每个会话一个 Docker 容器；默认没网、2GB 内存、最多 256 个进程；工作区挂到容器内 `/workspace`；`bash` 在容器里跑。Git 密钥、重启业务进程不要放进沙箱。

Forge 里的对应实现：

- 配置：项目根 `.env` + `backend/app/core/config.py`
- 逻辑：`backend/app/services/sandbox.py`
- 镜像：`infra/sandbox/Dockerfile`
- 开会话时启动：`duty.investigate` / `sessions.create_session` 调用 `ensure`

本文命令默认在 **PowerShell** 中执行。一行前面的 `#` 是说明，不是要你输入的命令。

---

## 第 0 步：做成什么样

- 打开一次「会话」→ `docker run` 一个长挂着的容器（里面只执行 `sleep infinity`，一直醒着）
- 跑命令 → `docker exec` 进这个容器执行
- 删会话 → `docker rm -f` 拆掉容器
- **不要**在 API 启动时给所有人建沙箱；第一次点「开会话 / 排查」再 `ensure`

本机必须先有 **Docker Desktop**。Python 只是用 SDK 喊 Docker 干活，自己不能代替 Docker 引擎。

## 第 4 步：写镜像配方并（可选）手编一次

文件：`infra/sandbox/Dockerfile`

```dockerfile
# 基础镜像：瘦身版 Debian + Python 3.12。沙箱里跑 bash/pytest 够用。
FROM python:3.12-slim-bookworm

# 更新软件源，并安装沙箱里常用的命令行工具。
# --no-install-recommends：少装附属包，镜像更小。
RUN apt-get update \
    && apt-get install -y --no-install-recommends \
        bash \
        ca-certificates \
        curl \
        git \
        nodejs \
        npm \
        ripgrep \
    && rm -rf /var/lib/apt/lists/*
    # 上一行删 apt 缓存，进一步减小镜像。
    # 注意：容器默认没网（network=none），装了 git/npm 也不等于能拉外网或用你的 SSH 密钥。

# 容器启动后的默认工作目录，和后面挂载的 /workspace 一致。
WORKDIR /workspace

# 容器主进程：一直睡，不退出。这样才能反复 docker exec 进来跑命令。
CMD ["sleep", "infinity"]
```

先手编一次，确认本机 Docker 能 build（代码里「没有镜像就现编」也是这一步）：

```powershell
# 进入项目根。
cd ./mysandbox

# -t 给镜像打标签 forge-runner:latest（和 .env 里的名字一致）。
# -f 指定 Dockerfile 路径。
# 最后的 infra/sandbox 是 build 上下文（Docker 在这个目录里找文件）。
docker build -t forge-runner:latest -f infra/sandbox/Dockerfile infra/sandbox
```

## 第 5 步：配置（.env + 读配置的 Python）

文件：项目根 `.env`

```env
# 沙箱镜像名。本地没有时 Python 会按 Dockerfile 现编并打上这个标签。
FORGE_SANDBOX_IMAGE=forge-runner:latest

# 容器内存上限。2g = 2GB，防止里面 fork 炸弹占满值班机。
FORGE_SANDBOX_MEMORY=2g

# 网络模式 none = 容器没有网。curl/pip 访问外网应失败。
FORGE_SANDBOX_NETWORK=none
```

**进程数 256 不写在 .env 里**，写在后面 `sandbox.py` 的 `pids_limit=256`。  
改 `.env` 后必须重启 Python 进程（配置有缓存）。

文件：`app/config.py`

```python
from functools import lru_cache  # 把函数结果记住，避免每次请求都重新读 .env
from pathlib import Path  # 拼项目根路径
from pydantic_settings import BaseSettings, SettingsConfigDict  # 把环境变量变成类字段


# config.py 在 app/ 下，parents[1] 是项目根 mysandbox/
ROOT = Path(__file__).resolve().parents[1]


class Settings(BaseSettings):
    # env_file：从项目根 .env 读；extra=ignore：多出来的环境变量不要报错
    model_config = SettingsConfigDict(env_file=str(ROOT / ".env"), extra="ignore")

    forge_sandbox_image: str = "forge-runner:latest"  # 对应 FORGE_SANDBOX_IMAGE
    forge_sandbox_memory: str = "2g"  # 对应 FORGE_SANDBOX_MEMORY
    forge_sandbox_network: str = "none"  # 对应 FORGE_SANDBOX_NETWORK


@lru_cache  # 整个进程只解析一次 Settings
def get_settings() -> Settings:
    return Settings()
```

## 第 6 步：Windows 挂载路径

Docker 在 Windows 上要正斜杠路径（例如 `D:/work/mysandbox`），不要反斜杠。

文件：`app/workspace.py`

```python
from pathlib import Path


def docker_bind(host_path: Path) -> str:
    """把宿主工作区路径交给 Docker 做 volume。反斜杠改成正斜杠，否则 /workspace 可能是空的。"""
    return str(host_path.resolve()).replace("\\", "/")  # resolve=绝对路径；replace=盘符格式
```

## 第 7 步：核心代码 ensure / exec / stop

文件：`app/sandbox.py`

```python
from pathlib import Path

import docker  # Docker 官方 Python SDK
from docker.errors import DockerException, ImageNotFound, NotFound  # 镜像/容器不存在等错误
from docker.models.containers import Container  # exec_run 返回的容器对象类型

from app.config import ROOT, get_settings
from app.workspace import docker_bind

# Dockerfile 所在目录，给 images.build 当上下文
DOCKERFILE_DIR = ROOT / "infra" / "sandbox"


class SandboxError(RuntimeError):
    """起容器失败时抛给上层，路由可变成 HTTP 500。"""
    pass


class SandboxManager:
    def __init__(self) -> None:
        self._client = docker.from_env()  # 连接本机正在跑的 Docker Desktop
        self._containers: dict[str, str] = {}  # 会话 id → 容器 id，避免每次都按名字查

    def _ensure_image(self) -> str:
        """本机没有镜像就按 Dockerfile 现编。"""
        settings = get_settings()
        image = settings.forge_sandbox_image  # 例如 forge-runner:latest
        try:
            self._client.images.get(image)  # 已有镜像则直接用
        except ImageNotFound:
            self._client.images.build(  # 没有则编译
                path=str(DOCKERFILE_DIR),
                dockerfile="Dockerfile",
                tag=image,
                rm=True,  # 编完删掉中间层，少占磁盘
            )
        return image

    def ensure(self, session_id: str, workspace: Path) -> str:
        """
        保证这个会话有一个正在跑的容器。
        有缓存就复用；停了就 start；没有才 docker run。
        返回容器 id。
        """
        name = f"forge-{session_id[:12]}"  # 容器名：forge- + 会话 id 前 12 位
        existing = self._containers.get(session_id)
        if existing:
            try:
                c = self._client.containers.get(existing)  # 按缓存的 id 取容器
                if c.status != "running":
                    c.start()  # 被人手动停过，再拉起来
                return existing
            except NotFound:
                self._containers.pop(session_id, None)  # 缓存过期，丢掉

        try:
            found = self._client.containers.get(name)  # API 重启后缓存空了，按名字找
            if found.status != "running":
                found.start()
            self._containers[session_id] = found.id
            return found.id
        except NotFound:
            pass  # 确实没有，下面新建

        image = self._ensure_image()
        settings = get_settings()
        try:
            container = self._client.containers.run(
                image,
                command=["sleep", "infinity"],  # 主进程一直挂着
                detach=True,  # 后台跑，不要占住 Python
                name=name,
                working_dir="/workspace",
                # 宿主工作区读写挂到容器 /workspace
                volumes={docker_bind(workspace): {"bind": "/workspace", "mode": "rw"}},
                network_mode=settings.forge_sandbox_network,  # 默认 none=没网
                mem_limit=settings.forge_sandbox_memory,  # 默认 2g
                pids_limit=256,  # 最多 256 个进程，写死在代码里
                stdin_open=True,  # 以后终端 exec 可能要用标准输入
                tty=False,  # 非交互 exec 不必分配伪终端
            )
        except DockerException as exc:
            raise SandboxError(f"Failed to start sandbox: {exc}") from exc
        self._containers[session_id] = container.id
        return container.id

    def exec(self, session_id: str, workspace: Path, command: str, timeout_s: int = 120) -> str:
        """在该会话容器的 /workspace 下跑一句 shell，把输出还给调用方。"""
        container_id = self.ensure(session_id, workspace)  # 容器可能被停过，先保证活着
        container: Container = self._client.containers.get(container_id)
        # 外层 timeout 防止命令挂死；!r 把 command 变成带引号的合法 shell 字符串
        wrapped = f"timeout {int(timeout_s)}s bash -lc {command!r}"
        result = container.exec_run(
            ["bash", "-lc", wrapped],  # 登录式 bash，能读常见环境
            workdir="/workspace",
            demux=True,  # stdout / stderr 分开
        )
        stdout, stderr = result.output if result.output else (b"", b"")
        out = (stdout or b"").decode("utf-8", errors="replace")  # 字节变文字，坏编码替换掉
        err = (stderr or b"").decode("utf-8", errors="replace")
        text = f"{out}\n{err}".strip() if err else out
        if result.exit_code not in (0, None):  # 非 0 表示命令失败
            return f"[exit {result.exit_code}]\n{text}".strip()
        return text.strip() or "(no output)"

    def stop(self, session_id: str) -> None:
        """删会话时拆掉容器。找不到就当已经没了。"""
        cid = self._containers.pop(session_id, None)  # 先清内存缓存
        name = f"forge-{session_id[:12]}"
        for key in (cid, name):  # 按 id 或按名字都能删
            if not key:
                continue
            try:
                self._client.containers.get(key).remove(force=True)  # 在跑也强制删
            except (NotFound, DockerException):
                pass


# 全进程共用这一份。不要在每个请求里 new，否则缓存对不上。
sandbox_manager = SandboxManager()
```

## 第 8 步：用脚本验证（先不接网站）

文件：`scripts/try_sandbox.py`

```python
from pathlib import Path
from app.config import ROOT
from app.sandbox import sandbox_manager

# 假装一次会话的 UUID（ensure 只用前 12 位当容器名）
sid = "11111111-2222-3333-4444-555555555555"
ws = ROOT / "workspaces" / "demo"  # 宿主上要挂进去的文件夹

cid = sandbox_manager.ensure(sid, ws)  # 第一次会 docker run
print("container:", cid)

print("ls:", sandbox_manager.exec(sid, ws, "ls -la"))  # 应能看到 hello.txt
print("cat:", sandbox_manager.exec(sid, ws, "cat hello.txt"))  # 应能看到 hello from host
# 没网时 curl 应失败；|| true 让整句不要把脚本弄崩
print("no net (should fail):", sandbox_manager.exec(sid, ws, "curl -s -m 3 https://example.com || true"))

sandbox_manager.stop(sid)  # 拆掉，避免本机堆容器
print("stopped")
```

运行（必须在项目根，并让 Python 找得到 `app` 包）：

```powershell
# 进入项目根。
cd ./mysandbox

# PYTHONPATH = 项目根，这样 python scripts\try_sandbox.py 才能 import app。
$env:PYTHONPATH = "./mysandbox"

# 跑验证脚本。第一次 ensure 若没镜像会先 build，可能要等一两分钟。
python scripts\try_sandbox.py
```

另开一个 PowerShell，在脚本还没 `stop` 之前（或把脚本里 stop 暂时注释掉）查看：

```powershell
# 列出名字以 forge- 开头的正在跑的容器。
docker ps --filter "name=forge-"

# 看这只容器的网络、内存字节数、进程数上限。
# 期望：net=none，mem=2147483648（即 2GB），pids=256。
docker inspect forge-11111111-22 --format "net={{.HostConfig.NetworkMode}} mem={{.HostConfig.Memory}} pids={{.HostConfig.PidsLimit}}"
```

`{{.HostConfig.NetworkMode}}` 是 Docker 模板语法：取出检查结果里「网络模式」字段。不是 PowerShell 变量。

## 第 9 步：接到三个 HTTP 接口

不要在 FastAPI **启动**时建沙箱。Forge 是点排查 / 新建会话时才 `ensure`。

文件：`app/main.py`

```python
from pathlib import Path
from fastapi import FastAPI, HTTPException
from app.config import ROOT
from app.sandbox import SandboxError, sandbox_manager

app = FastAPI()
WORK = ROOT / "workspaces" / "demo"  # 演示用固定工作区；真项目应来自会话表


@app.post("/sessions/{session_id}/open")
def open_session(session_id: str):
    """对应 Forge：investigate / create_session 里那次 ensure。"""
    try:
        cid = sandbox_manager.ensure(session_id, WORK)
    except SandboxError as e:
        raise HTTPException(500, str(e))  # Docker 没开、权限不够等
    return {"ok": True, "container": cid}


@app.post("/sessions/{session_id}/bash")
def run_bash(session_id: str, command: str):
    """对应 Forge：人批准后的 tools.bash → exec。真项目应先做安全检查。"""
    return {"output": sandbox_manager.exec(session_id, WORK, command)}


@app.delete("/sessions/{session_id}")
def close_session(session_id: str):
    """对应 Forge：delete_session → stop。"""
    sandbox_manager.stop(session_id)
    return {"ok": True}
```

启动 API：

```powershell
cd ./mysandbox
$env:PYTHONPATH = "./mysandbox"

# --reload：改代码自动重启（开发用）。--port 8788：避免和 Forge 的 8787 撞车。
uvicorn app.main:app --reload --port 8788
```

另开终端调用（Windows 10 若没有 curl，可用浏览器插件或 `Invoke-RestMethod`）：

```powershell
# 开会话：这时才 docker run（若还没有容器）。
curl -X POST http://127.0.0.1:8788/sessions/aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee/open

# 在笼子里执行 ls。command 是查询参数。
curl -X POST "http://127.0.0.1:8788/sessions/aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee/bash?command=ls"

# 删会话：拆掉容器。
curl -X DELETE http://127.0.0.1:8788/sessions/aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee
```

PowerShell 等价写法：

```powershell
# POST 开会话，返回 JSON。
Invoke-RestMethod -Method POST -Uri http://127.0.0.1:8788/sessions/aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee/open

# POST 跑 ls。
Invoke-RestMethod -Method POST -Uri "http://127.0.0.1:8788/sessions/aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee/bash?command=ls"

# DELETE 拆笼子。
Invoke-RestMethod -Method DELETE -Uri http://127.0.0.1:8788/sessions/aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee
```

## 第 10 步：以后接到 Agent（有 SDK 再做）

建议顺序，不要和沙箱第一步绑死：

1. **闸门**：`exec` 前先 `assert_safe_bash`（禁 `git reset --hard`、force push、扫 C 盘等）。
2. **人工批准**：`bash` 标需要批准；没点允许不要进 `exec`。
3. **热修测试**：工作区有 `.forge-host-tests` 就在**宿主**跑 pytest，不要进沙箱。
4. **`git_*` / 重启服务 / `write_file`**：走宿主 + 路径闸门，不要 `docker exec`。

调用关系保持：

```text
开会话路由  → sandbox_manager.ensure    # 笼子起来
bash 工具    → 安全检查 → exec           # 命令进笼子
删会话       → stop
```

```text

  → 只 import 了全局 sandbox_manager

  → ensure(session_id, 工作区)     ★ 第一次 docker run

模型 read_file
  → 不进沙箱，Python 直接读宿主文件

模型要 bash，你点允许
  → exec                           ★ docker exec 进已有笼子

  → 宿主跑（有 .forge-host-tests）  不进沙箱

你删会话
  → stop                           拆容器
```

## 常见坑

| 现象 | 原因 |
|---|---|
| `docker.from_env()` 报错 | Docker Desktop 没打开 |
| 容器里 `/workspace` 是空的 | 挂载仍用了 `D:\...`，要用 `docker_bind` |
| API 一启动就很多容器 | 错误地在 lifespan 里 ensure；应对齐「开会话才起」 |
| 以为沙箱能代替「只能改 bugs.py」 | 工作区是 **rw 挂进去的**；改哪个文件仍要路径闸门 |
| 沙箱里 git push 失败 | 默认没网、没有宿主凭据；提交应走宿主 `git_*` |
